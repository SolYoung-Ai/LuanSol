# LunaSol 2.0 阶段五：实际尺寸样品打样验证流程

状态：流程已定义，实体打样未执行。
对象：真实项目“是谁谁谁”，护肤瓶身标签。
成品：62×62mm，瓶身 62×62×180mm。
展开：68×68mm（每边 3mm 出血），安全区 5mm。
文件：`是谁谁谁_印刷稿.pdf`、`是谁谁谁_刀模_矩形标签.dxf`、展开稿 SVG。

## 0. 先决条件

- 设计文件来自当前生产构建，印前状态不是 error。
- PDF 为真实毫米页面，不是屏幕截图。
- DXF 为真实毫米几何，不是 SVG 改后缀。
- 不需要在 LunaSol 里重新改结构；这次只验证标签。

## 1. 文件核对

| 项 | 期望 | 实际 |
|---|---|---|
| PDF 页数 | 3 页：PRINT / CUT / CREASE | 3 |
| PDF 页面 | 68×68mm | 192.7559×192.7559pt = 68×68mm |
| CUT 标记 | `LunaSol CUT` | 1 次 |
| CREASE 标记 | `LunaSol CREASE` | 1 次 |
| 工艺页 | 无（项目未使用烫金 / UV / 专色） | 0 |
| DXF 单位 | `$INSUNITS=4`、`$MEASUREMENT=1` | 是 |
| DXF 范围 | 0..68mm | `$EXTMIN 0,0` / `$EXTMAX 68,68` |
| DXF 裁切框 | 3..65mm 矩形 | 4 条 LINE：3..65 |
| SVG 尺寸 | `width=68mm` / `height=68mm` | 由同一份 dieline 生成 |

任何一项不符，停止打样，先查导出，不要靠印厂缩放补救。

## 2. 纸样打印

1. 用 Acrobat 或印厂 RIP 打开 PDF，确认页面框为 68×68mm。
2. 打印设置选“实际大小 / 100%”，关闭“适合页面”。
3. 白纸打印第 1 页 PRINT。
4. 用钢尺量：
   - 页面外框 68mm；
   - 裁切框 3..65mm，即 62mm；
   - 安全区 8..60mm，即 5mm 内缩。
5. 把纸样卷到瓶身，确认 62mm 横向贴合、文字方向正确、接缝不压在主视觉上。

判定：尺寸误差超过 0.5mm 或打印缩放不等于 100%，重打。

## 3. 刀模确认

把 DXF 发给刀模厂，要求对方回报：

- 单位识别为 mm；
- 版面 68×68mm；
- 只有一条矩形裁切，位置 3..65mm；
- 没有多余压痕（矩形标签不应有折线）；
- 刀口补偿由刀模厂按材料与刀线自行处理，LunaSol 不提供补偿值。

回执必须写明：刀模编号、材料、刀线长度、补偿值、制作日期。

## 4. 材料与工艺确认

打样前确认，不接受口头默认：

| 项 | 需确认 |
|---|---|
| 面材 | 铜版纸 / 合成纸 / PE / PET / 其他 |
| 克重 / 厚度 | g/m² 或 μm |
| 胶水 | 永久 / 可移 / 冷冻 / 其他 |
| 表面 | 哑光 / 亮光 / 触感膜 / 无 |
| 透明 | 是否透明、是否需要白墨打底 |
| 印刷 | 数码 / 胶印 / 柔印 / 其他 |
| 专色 | 是否有 Pantone；LunaSol 当前只出工艺 mask，不替代专色通道 |

如果选透明材料且设计有透明底图，必须确认白墨位置；LunaSol 印前会对“透明图叠在无底色面”报 error，但不会自动生成白墨版。

## 5. 打样顺序

1. 白样：只裁切、不印刷，确认尺寸、贴合、翘边。
2. 色样：按确认的材料和工艺印刷，至少 3 张。
3. 成品样：裁切、贴标、上瓶，静置 24 小时观察翘边和溢胶。

## 6. 验收标准

| 项 | 通过标准 | 记录 |
|---|---|---|
| 尺寸 | 68×68mm，裁切框 62mm，误差 ≤0.5mm | 实测值 |
| 套印 | 主要元素套印偏差 ≤0.2mm | 放大镜 / 照片 |
| 文字 | 无裁切、无糊版；1.5mm 以下小字可读 | 照片 |
| 色差 | 与屏幕稿对比，ΔE ≤ 3（数码）或印厂认可范围 | 色差仪 / 目测 |
| 贴合 | 圆周贴合不翘边，24 小时后无起翘 | 照片 |
| 表面 | 无划伤、无脏点、无气泡 | 照片 |
| 刀模 | 裁切边缘整齐，无锯齿、无过切 | 照片 |

真实项目已知风险：印前报告 2 处文字进入 5mm 安全区、4 处文字小于 1.5mm。打样前应调整或由印厂书面确认“可接受”，否则不进入批量。

## 8. 尚未验证

- 实体纸样、刀模实物、上机印刷均未执行。
- 纸厚、折叠补偿、插舌间隙未验证；本样品是平面标签，不涉及折叠盒。
