# AI 模型配置说明

LunaSol 是**纯静态站点**，不依赖任何自有后端。所有 AI 能力都通过用户自己配置的 **OpenAI 兼容接口**完成。

## 1. 在哪里配置

打开网站 → 右上「开始设计」旁的导航进入 **AI 模型配置中心**（`#/models`），或从「个人设置」跳转。

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| Base URL | OpenAI 兼容根地址 | `https://api.openai.com/v1` |
| API Key | 你的密钥 | `sk-...` |
| 文字模型 | 用于需求理解与对话修改 | `gpt-4o-mini` |
| 图像模型 | 用于生成原创插画素材 | `gpt-image-1` |
| 启用 AI 图像生成 | 开启后方案页出现「用 AI 生成真实插画素材」 | — |
| 温度 / 重试 | 生成参数与失败重试次数 | 0.7 / 1 |

点「测试连接」会真实调用一次 `/chat/completions` 并显示模型回复或错误信息；点「保存配置」写入浏览器 localStorage。

## 2. 调用的接口

**文字**：`POST {Base URL}/chat/completions`

```json
{
  "model": "<文字模型>",
  "messages": [{ "role": "system", "content": "..." }, { "role": "user", "content": "..." }],
  "temperature": 0.7,
  "response_format": { "type": "json_object" }
}
```

用途：
- 需求理解 Agent：把整段对话整理成结构化 JSON（产品、品类、品牌、风格、配色、图案、文案、建议）。
- 对话修改 Agent：把用户一句话转成**局部修改补丁**（最多 3 个 op），不重新生成整张包装。

**图像**：`POST {Base URL}/images/generations`

```json
{ "model": "<图像模型>", "prompt": "Original packaging illustration, no text...", "n": 1, "size": "1024x1024", "response_format": "b64_json" }
```

支持返回 `b64_json` 或图片 URL；生成结果作为**独立图片图层**加入正面，文字仍保持可编辑。

## 3. 错误处理

- 文字 60s / 图像 120s 超时；可配置 0–3 次重试。
- 调用失败时自动回退到内置引擎，并在界面明确显示「AI 修改未成功，已使用内置规则」，**不会把模拟结果说成 AI 生成**。
- 未配置 API Key 时，AI 相关按钮会引导去配置页，其余功能全部可用。

## 4. 安全说明（务必阅读）

- **静态网站无法安全隐藏第三方 API Key。** LunaSol 源码中没有任何硬编码密钥。
- 密钥只保存在**当前浏览器的 localStorage**，请求由浏览器直连你填写的 Base URL，不会经过 LunaSol 的任何服务器。
- 不要在不可信的第三方站点填写生产密钥；不要把密钥写进公开仓库（`.env` 已加入 `.gitignore`）。
- 三种接入方式：
  1. **本地直连**（个人使用，成本最低）：浏览器直接请求模型服务。
  2. **用户自有代理**（小团队）：把 Base URL 指向自己部署的服务端代理，由代理保管密钥。
  3. **可选安全网关**（未来）：统一做额度、审计与密钥轮换；当前版本不依赖任何虚构后端。

## 5. 未配置时的能力

可手动创建项目、使用内置基础方案、编辑文字、上传图片、手动排版、保存恢复项目、导出基础 PDF / SVG / DXF / PNG / JPG。内置方案是**确定性的程序化设计**（原创矢量插画 + 可编辑文字图层），界面会如实标注，不冒充 AI 生成。
