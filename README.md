# LunaSol · AI 智能包装设计平台

> 说清楚要做什么包装，剩下的交给 AI。
> **LunaSol AI Packaging Studio** — 面向没有设计经验的人的包装设计工作流。

线上地址：<https://luna.solyoung.top/>

---

## 它解决什么问题

盒型、刀模、出血、安全区、CMYK、字体转曲——传统包装设计把这些前置条件全部压在用户身上。
LunaSol 把它们放到后台，用户只需要回答三个问题：做什么包装、多大、叫什么。

```
描述需求 → AI 理解 → 生成方案 → 选一个 → 对话修改
        → 3D 预览 → 印前检查 → 导出印刷文件
```

## 核心能力

| 环节 | 做什么 |
| --- | --- |
| 需求理解 | 中文自然语言解析：尺寸单位、品类、品牌、风格、配色、图案、规格；不确定的地方逐个问，不一次抛一堆问题 |
| 结构与刀模 | 七种结构的真实几何展开（插舌盒、天地盖、抽屉盒、飞机盒、自立袋、矩形标签、圆形标签），含 3mm 出血与 5mm 安全区 |
| 方案生成 | 一次给三个明显不同的方向（极简 / 插画 / 商业），每个方向配色、字体、构图各自成套，不是同一套换个颜色 |
| 可编辑设计稿 | 输出的是分层矢量稿——文字、图形、图片各自独立可改；不把一张图片当设计稿交差 |
| 对话修改 | 说一句「主标题再大一点、换成深绿」，只改该改的图层，其余锁定不动，并保留历史版本 |
| 3D 预览 | 每个面独立贴图，盒盖可开、抽屉可拉、标签贴曲面；材质、背景、光照可调，可导出效果图 |
| 印前检查 | 尺寸、出血、安全区、文字是否被裁、是否还有占位文字、图片有效 DPI、颜色 CMYK 值、字体可用性、刀模完整性 |
| 文件输出 | 毫米级 PDF（图形与刀模为矢量）、可编辑 SVG、DXF 刀模、300DPI PNG、JPG 效果图、ZIP 交付包 |

包装结构库、作品工作台、项目详情与历史版本、复刻（参考图 + 素材图一次出三张）、账户与积分、帮助中心，均在站内。

## 技术栈

- **前端**：React 18 + TypeScript + Vite，hash 路由，按路由拆分代码
- **图形**：自研矢量排版与刀模引擎（几何计算，不依赖 AI 判断可生产性）+ Three.js 3D 预览
- **后端**：腾讯云 CloudBase —— 身份认证、PostgreSQL（行级安全）、云函数、静态托管
- **AI**：文本与图像模型由平台统一接入并托管密钥，前端不持有任何厂商 Key；模型不可用时自动回退内置设计引擎，并在界面上如实标注

## 使用边界

包装设计最终要落到印刷机上，所以有些事我们明确不做承诺：

- **不做 PDF/X-4**：没有经过标准符合性验证，就不会把普通 PDF 标成 PDF/X-4
- **CMYK 为近似换算**，未内嵌 ICC 配置文件，屏幕色与印刷色存在差异，投产前请打样
- **PDF 中的中文文字按设定 DPI 栅格化嵌入**（等效转曲，避免印厂缺字）；SVG 保留可编辑矢量文字
- **法规信息需用户自行核实**：食品、化妆品等标签的成分、净含量与宣称，系统只检查完整性与排版，不宣称合规
- **结构由几何计算得出**，极端比例会给出警告，但量产前仍建议与印厂确认
